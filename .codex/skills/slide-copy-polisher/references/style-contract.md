# Direct-copy style contract

## Text roles

| 角色 | 只负责什么 | 推荐句式 | 需要删除的内容 |
|---|---|---|---|
| 主标题 | 给出本页判断 | “问题集中在数据链断裂” | 主题名、背景铺垫、无结论的名词串 |
| 模块标题 | 标出一个板块动作 | “先过资格门槛” | “关于……的说明”“进一步分析” |
| 正文 | 解释证据和关系 | “报名窗口只有六天，错过后不能补报。” | 同义改写、空泛形容、连续从句 |
| 结论 | 给出影响或动作 | “先补数据，再谈模型。” | 把正文再抄一遍、无动作的总结 |
| 图注 | 说明画面对象和来源 | “装置热试车现场 / NASA, 2023” | 画面没有的推断、泛化评价 |
| 讲稿 | 连接本页与下一页 | “这一页先看门槛。下一页进入时间窗口。” | 照读页面、通用客套、与本页无关的背景 |

## Four editing passes

### 1. 先给判断

把最重要的主语、动词和结果放到句首。避免先解释“为什么要讲这件事”，再迟迟落到结论。

### 2. 删除防御和迂回

优先删除这些没有新增事实的开头或连接：

- “需要指出的是”“值得注意的是”“不难发现”“毋庸置疑”；
- “从某种意义上说”“在一定程度上”“总体而言”“可以说”；
- “通过……可以”“围绕……展开”“基于……进行”“从……来看”；
- “由此可见”“在此基础上”“进一步说明”。

如果限定语改变事实边界或不确定性，保留信息本身，改成短句。例如“结果可能受样本量影响”保留“可能”，但不要再加“在一定程度上”。

### 3. 去除实质性重复

一页通常只保留一处完整判断。标题说结论，正文给证据，底部结论给行动或影响。不要让三处都写“数据质量决定模型效果”。可以改成：

- 标题：“模型效果先受数据质量限制”；
- 正文：“缺失值集中在两类工况，训练集因此失去代表性”；
- 结论：“先补齐工况覆盖，再比较模型”。

### 4. 拆句和换标点

一个句子只保留一个主要动作。长句按“事实 / 关系 / 动作”拆开。禁止用破折号承载第二个判断；改用句号或冒号。分号只连接同一层级的短分句，不能把四五个动作串成一行。

## Capacity and fidelity

- 先满足内容模块的最小、最大字数和固定行数，再调整句法。
- 标题仍要保持模板要求的一行或两行，并保留混色关键词的语义角色。
- 不自动删掉句尾、数字、限定条件、来源或时间。容量不足时重写整句。
- 不把“说明、操作、要点、相关内容”等空词塞进文本框。
- 图注只写观众能从画面和来源核验的对象、机构、作者和年份。

## Review checklist

逐槽检查：

1. 读第一句能否知道这一槽要表达什么。
2. 是否存在没有新增信息的铺垫或重复。
3. 是否有一个句子承担多个动作或多个转折。
4. 是否出现破折号、长串分号、套话或不必要的模糊词。
5. 是否保留了事实、数字、来源、术语和结论强度。
6. 渲染后固定标题行数、容量、行距和阅读顺序是否仍成立。
